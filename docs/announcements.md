# 更新提示与重要通知

管理台的「更新与通知」可创建多条版本更新与重要通知。客户端采用原生 SwiftUI 卡片，支持深色模式、动态字体与滚动长文；正文使用有限 Markdown，不嵌入 WebView。需要图片、视频或复杂排版时，通过 HTTPS 详情链接打开网页。

## 发布流程

1. 点击「新增消息」，选择消息类型和适用平台。
2. 填写标题、可选副标题和正文。正文支持 `#` / `##` / `###` 标题、`-` 或 `*` 列表、粗体、斜体、行内代码、引用和 HTTPS 链接。HTML 与脚本不执行，图片不加载。
3. 版本更新必须填写目标 App 版本与 HTTPS 更新链接，例如 App Store 或 TestFlight 地址。按钮文字可自定义。普通通知无需链接也能发布。
4. 可选填最低、最高适用 App 版本（均包含边界）以及开始、结束时间。版本填 `1.2.0` 这样的数字 App 版本号，不是操作系统版本或构建号。时间按管理者浏览器本地时区输入，保存为 Unix 秒。
5. 勾选「启用发布」，点击「保存发布配置」。未启用的条目保存为草稿。取消启用或删除后保存即可下线；客户端前台每 5 分钟检查，设置页可手动刷新。

每次最多保留 30 条消息，正文上限 12,000 字符。后台预览展示内容层级，最终排版以 App 为准。配置持久化到 SQLite，管理员保存会记录操作日志。若其他管理员已先保存，旧编辑页会拒绝覆盖，请重新加载后再编辑。

## 展示规则

- 复用试用到期提醒的前台调度：启动后等待 3 秒，每 15 秒重新检查可展示条件；仅在课表首页、无其他弹窗或云同步确认时展示。
- 避开用户自己的课程、正在关注的共享课程及各自课前 10 分钟。课间可展示；课表时间不明确时继续等待。
- 重要通知优先，其次版本更新，最后试用提醒。通知按后台列表顺序展示（新建消息在顶部）；多个适用更新只自动提示最高目标版本，不回退弹出较旧的更新。
- 版本更新和重要通知均不受 24 小时限制，但距上一次自动提示至少间隔 5 分钟，避免连续弹窗；试用提醒仍需距上一次自动提示至少 24 小时。每条通知每台设备自动展示一次，关闭或「稍后再说」后不重复弹出。新版本提示按消息 ID 与目标版本去重。
- 正在购买或有其他弹窗时会等待；购买结束后残留的错误消息不会阻止版本更新和重要通知。
- 已安装版本等于或高于目标版本时不提示更新。版本按数字分段比较，例如 `1.10 > 1.9`，`1.2 == 1.2.0`。
- 生效窗口为开始时刻（含）到结束时刻（不含）；草稿和窗口外消息不会通过公共接口返回。
- 只有页面实际出现才记录已展示；被上课或其他页面推迟时不会消耗提醒机会。修改原消息标题、正文不会再次弹出；要重新通知，请新增消息。
- 设置 →「更新与通知」可主动查看所有当前适用消息，也会记录已读；手动查看不受自动提示的间隔限制。无网络或旧服务端没有接口时静默跳过自动提示，设置页提供重试，不影响课表使用。

自动提醒记录保存在本机，不通过 iCloud 同步。服务端下线消息后，客户端下一次成功检查即移除；已经打开的详情页不会被突然关闭。本功能是 App 内前台提示，不是 APNs 推送，不包含强制更新。

## API

- `GET /v1/announcements`：公开读取已启用且在生效时间内的消息，无设备信息上传。
- `GET /v1/admin/announcements`：管理员读取完整配置（包括草稿、过期消息）与 `revision`。
- `POST /v1/admin/announcements`：使用管理台相同的管理员会话或 `X-Admin-Token`，提交当前 `revision` 和完整 `messages` 列表。保存成功后 `revision` 自增；陈旧版本或无效内容返回 400，未授权返回 403。

示例（先读取当前 revision，再提交）：

```json
{
  "revision": 0,
  "messages": [
    {
      "id": "release-1-10-ios",
      "kind": "update",
      "platform": "ios",
      "enabled": false,
      "title": "新版本，带来更从容的日常",
      "subtitle": "本次更新的简短介绍",
      "body": "## 这次的变化\n- **新功能**：填写真实的更新内容\n- 修复与体验优化",
      "version": "1.10.0",
      "minVersion": "",
      "maxVersion": "",
      "actionTitle": "前往更新",
      "actionURL": "https://apps.apple.com/",
      "startsAt": null,
      "endsAt": null
    }
  ]
}
```

`kind` 为 `update` 或 `notice`；`platform` 为 `all`、`ios`（含 iPadOS）、`macos` 或 `visionos`。示例链接应替换为真实产品地址，确认版本已可下载后再启用发布。

## 验证

- `bash tests/check-announcements.sh`：数字版本、适用范围、平台、生效边界、链接、优先级、去重与公共间隔。
- `bash tests/check-trial-reminders.sh`：原有试用提醒和课程避让回归。
- `uv run --frozen python -m unittest tests.test_announcements -v`：发布校验、权限、持久化、冲突保护及草稿/定时/下线过滤。
