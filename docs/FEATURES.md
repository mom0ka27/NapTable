# NapTable 功能说明

本文档记录面向使用者的功能行为。项目结构、平台兼容性、签名和测试命令见[开发与构建](DEVELOPMENT.md)；服务端运维与 API 见[服务端说明](../server/README.md)；实时活动协议见 [Live Activity v2](live-activity-v2.md)。

## 课表视图

顶栏提供日、周、月三种视图，共用学期选择、溢出菜单和课程编辑入口。

- 日视图和周视图使用按节次排列的课表网格，可以按天或按周翻页。
- 月视图使用日历布局，每格显示公历日、农历或节日，以及表示当天课程数量的横条；点击日期后，在弹窗中列出当天课程。
- 月视图中的「日视图」入口会跳到选中日期所在的教学周。
- 课程可以来自教务导入，也可以手动添加、编辑或保留为自定义课程。
- 学校不在列表里时，「其他学校 / 手动创建」会引导用户依次设置第一周的星期一和学期总周数、节次时间（可按上午/下午/晚上的起始时间、课时和课间快速生成），再逐门添加课程。每门课可以有多个上课时间，周次支持每周、单周、双周和逐周自选；时间冲突会提示但不拦截。学期、周数和节次保存在这张课表上，之后在「设置 › 我的课表」里修改。首次使用的引导里也有这个入口，这时至少要添加一门课才能完成引导。
- 没有固定星期和节次的自由时间课程通过顶栏的时钟按钮单独查看，角标显示当前周的课程数量；翻周和切换课表时入口保持固定，不挤动课表。显示设置开启时，没有自由时间课程的课表保留灰色的 0 按钮。
- 课表支持生成图片分享和导出 ICS 日历文件。

专业版可以在「我的课表 → 课表设置 → 背景图片」为每张课表单独设置背景；浅色模式和深色模式各自保存一张图片，也可以只设置一张让两种外观共用。未单独设置的课表沿用默认背景，之后设置时才会建立独立副本。

## 农历、节日与调休

农历和节日由 `WidgetCore/ChineseCalendar.swift` 离线计算，App 与小组件共用同一套结果，并按公历年缓存。

- 支持常见农历节日、部分公历节日和法定假期提示。
- 月视图始终显示农历和节日；小组件可单独控制农历日期、节假日提示和始终显示最近节假日。
- 法定节日按固定规则计算；学校配置启用时，服务端还会分别应用国务院每年发布的放假和补班安排。
- 调休由服务端学期配置按日期覆盖：`off` 表示当天放假，`swap` 表示当天改上指定日期的课。
- 补班日显示被补日期的课程，放假日不显示课程；周视图和月视图会显示相应的「班」「休」标记。

## 小组件

小组件不直接访问网络。App 将当前课表编码为 payload 写入 App Group，扩展从共享存储读取并生成时间线。

- 提供两个小组件：「今日课程」小号、中号和锁屏显示当前与下一节课，大号显示今日完整课表；「两日课表」只有大号。
- 大号今日课表和两日课表可在「编辑小组件」里选择显示方式：时间线（左侧起止时间，卡片按时长分高度、标出较长的课间）或列表。今日课程默认时间线，两日课表默认列表。
- 默认只展示当天课程；当天课程结束后，可以选择显示明天课程、保持「今天没有课程」，或显示最近节假日。
- 时间线会在课程开始和结束边界额外刷新，不必等待固定刷新周期。
- 小组件使用与 App、实时活动共享的主题和显示选项。
- 专业版可在「设置 → 桌面小组件 → 背景图片」配置主屏幕小组件的背景，浅色和深色分别保存图片、裁剪位置和不透明度，只设一张时共用。今日课程和两日课表共用这组背景，并按尺寸居中裁切。图片保存在本机 App Group 中，锁屏组件使用系统背景，染色模式与待机显示由系统决定背景效果。
- 点击小组件会通过 `naptable://schedule` 回到 App。

## 实时活动与灵动岛

实时活动只展示当天的课程。课程进入设置的提前显示窗口后出现，下课时结束或切换到当天的下一节课。

- 提前显示时间可选 15 分钟、30 分钟或 1 小时，默认 1 小时。
- 开启「课间也保留」后，课间会继续显示并倒计时到今天的下一节课；当天没有后续课程时自动收起。
- 今天第一节课尚未进入提前显示窗口时，不会一早显示晚上的课程。
- App 被系统挂起时，后台任务会尝试在课程边界收起或切换实时活动；系统可能调整实际执行时刻。
- 打开「显示实时活动」后，App 把课表的节次、周次和提醒设置上传给服务端（不含课程名、教师和教室），由服务端算出每节课的提醒时间并通过 APNs 启动活动，不打开 App 也会一直提醒到学期结束。iOS 26 及以上还会在本机预约最近几节。iOS 17 只能预览效果。
- 实时活动首次开启可免费试用 30 天，试用不会自动扣款；到期后可通过 Apple App Store 一次买断并在其他设备恢复。没有试用或买断权益时，服务器不会安排新的实时活动。
- 课程文案由 App 根据本机课表生成；服务端的推送只标出这个活动的时间段。共享课表的课例外：推送里带着服务端上的分享内容，手机上的分享还没更新时也能显示对方的新课。
- 提示来源是共享课表时，实时活动会标出这张课表的名字；如果自己同一时间也在上课，灵动岛和锁屏会把两节课并排显示，各自倒计时；两边的连堂课都按本机「分节计时」设置决定是否分节、是否显示课间。
- 关心共享课表时两张课表合在一起提醒：自己的课和对方的课分别按各自的提前显示时间提醒（设置页多一个「共享课程提前显示」）；两边时间重叠的课合成一个实时活动：自己的课在上时自己的课占主位、对方的课并排，否则对方的课在上；都没在上课时倒计时到最近的下一节。不重叠的课各自单独提醒。合并活动已经在显示时，后加入的课到了它的提前显示时间会再响一次「课程提醒」。一串相互重叠的课超过 8 小时时，在显示变化的时刻交给下一个实时活动。
- 分享者更新或撤销分享后，服务端会直接替关心的人重新安排，不需要对方打开 App。
- 走学校作息的课表由学校的公共上下课广播刷新画面；关心共享课表或作息与学校不一致时，每个实时活动由服务端在显示变化的时刻单独推送刷新。

## 专业版权益与试用提醒

- 设置页顶部展示专业版入口、当前试用或买断状态，以及实时活动、高级主题设置、小组件背景图片三项专属功能。进入权益页默认展示专业版。
- 30 天试用剩余 3 天内、到期后，各自动展示一次权益提醒；两个阶段至少间隔 24 小时。提醒说明一次买断、到期不会自动扣款，以及仍可免费使用的功能，可随时关闭。
- 仅在 App 前台课表页空闲时展示，不打断导入、编辑、购买或 iCloud 确认。上课期间和整段课程第一节开始前 10 分钟顺延；连堂课中间的课间允许展示，不计入后续节次的课前保护时间。
- 避让按实际日期、教学周、调休与当天作息计算，同时检查自己的课表和已关心的共享课表。Beta 免费期间、已买断或从未试用的用户不会收到到期提醒。

## 从教务导入

目前开放南京大学（本科生、研究生教务与选课）、中山大学、南京林业大学、南京审计大学、南京工业大学、复旦大学本科生教务、西安交通大学 eHall、浙江大学本科生教务网、中国人民大学本科/研究生教务系统以及上海科技大学本科生和研究生课表的网页导入：在 App 内的学校页面登录，到达课表页后自动读取当前学期课表。南京林业大学经统一认证登录后回到教务系统任意页面即可，脚本会自己读取「学期理论课表」。南京审计大学经统一认证回到学生教务系统后读取「本学期课表」，支持单双周、多地点和不连续节次；未排课的课程保留为自由时间课程。南京工业大学登录后进入「学生个人课表」，脚本读取正方课表接口的普通课、实践课和教学环节课程，支持单双周。复旦大学登录新版教务系统并进入「我的课表」后，脚本读取当前学期的 `print-data` JSON，解析课程名称、教师、地点、周次和节次。浙江大学经统一认证进入本科教务网课表页面后，脚本按当前学年学期请求 `kbList`，解析课程名称、教师、教室、单双周和节次；作息与开学日期由服务端学校学期配置校准。

中国人民大学本科入口先打开 `cas.ruc.edu.cn` 统一身份认证，登录完成后进入教务首页，等待首页初始化后自动打开 `jw.ruc.edu.cn`「课表查看」读取完整课表。优先按页面课程组件的星期字段解析，兼容地点/节次/连续、不连续或单双周文本以及未指定教室的课程；首页上的课表预览不作为自动导入目标。研究生入口读取 `yjs2.ruc.edu.cn`「学生课程表」网格，并兼容同源 iframe。两条入口都按页面显示的学年学期匹配服务端校历和作息。

上海科技大学提供研究生课表入口，参考 [shanghaitech-timetable](https://github.com/Benedict999/shanghaitech-timetable)。用户在学校统一身份认证页面登录研究生综合服务平台，进入「学生课程表」（我的课表）并选择学期后，App 在同源 iframe 中通过 `loadPkjg.do` 读取该学期全部排课。支持连续、不连续和单双周、周末调课、不同节次数，以及各次排课的教师和教室；门户内异步加载课表时会自动等待，也可点「重新解析」。选课但尚未排课的课程不在该接口的排课结果中。接口异常或排课数据不完整会停止本次导入，现有课表保持原样。学期名称来自学校选择器，校历和作息匹配学校 ID `shanghaitech` 的服务端配置。

上海科技大学本科生入口参考 [ShangHaITech](https://github.com/Lceoliu/ShangHaITech) 的校园服务定位，使用学校本科教务系统（EAMS）和统一身份认证。登录后进入「学习管理」→「我的课表」，脚本从当前页面的课表明细或网格读取课程名称、课程代码、教师、教室、星期、节次和周次；支持不连续周次、单双周、周末课程、晚间节次和同一课程多个时段。App 只复用登录后的 WebView 会话，不保存账号密码或 Cookie。学期名称来自课表页面，校历和作息匹配学校 ID `shanghaitech` 的服务端配置。

西安交通大学通过统一认证登录 eHall，选择学生角色并进入「我的课表」后，读取教务接口给出的当前学期学生课表。周次优先采用 `SKZC` 位掩码，兼容展示文本中的单双周和不连续周；保留每个时段的教师、教室和校区。同一门课程的多个时段和不同教室分别导入，学期代码用于匹配服务端的开学日期和作息配置。

西交大标准作息按实际上课日期自动切换：每年 5 月 1 日起用夏、秋季时间，10 月 1 日起用冬、春季时间。课表预览、小组件、日历导出、本地实时活动预约和 APNs 提醒使用同一天的作息；调休补课按补课当天的作息上来源日期的课程。日视图展示当天的节次时间。创新港等其他作息可由管理员编辑或关闭分季作息。

导入的课程在写入课表之前会先检查时间冲突：同一天、节次相交、并且确实有共同周次的两行才算撞车（单双周轮流上的课节次虽然重合，但不会被误报）。

- 重叠课程按组呈现，必须选择优先显示的课程才能导入；追加导入时也检查当前课表已有课程。首位课程未覆盖的周次或节次仍有重叠时，继续选择剩余区域的优先课程。所有选择只改变显示顺序。
- 所有课程完整保留并计入课表，包括完全相同的重复记录。未选中的课不会被收起，也不会删除或拆掉重叠周次。
- 长按课程卡片，或进入「设置 → 编辑课表」，可修改课程信息、显示优先级和上课安排。每组安排可分别多选周次、星期和节次，支持不连续节次与多组安排。
- 长按编辑页顶部可切换同一时段的课程，包含非本周和已收起的安排；各页修改暂存在草稿中，保存时一起生效，取消不会写入。可在编辑页调整优先显示的课程。
- 实时通知按保存的优先级选择每节显示的课程，只在实际重叠时取首位；其他周次、节次的课程照常提醒。客户端把优先级展开为日期节次选择，兼容旧服务端；共享课表和关心模式也使用优先级。
- 「编辑课表」可切换本机课表，并查看、编辑非本周与已收起的课程。旧版本收起的课程也可恢复。

## 学校配置与课表分享

NapTable 服务端可以集中保存学校的学期开始日期、总周数、节次时间和调休表。App 导入课表时按学校和学期匹配配置，并缓存配置供离线使用。

分享内容是「课程 + 发布时的学校学期时间配置」的快照，包含节次时间、第一周周一、总周数和调休。因此读取他人分享时，不需要本机配置对方学校，也不会错误套用自己的作息。

- 分享码用于读取，写入和撤销使用创建分享时返回的一次性 `writeToken`。
- 分享者可以在「分享课表」页面撤销分享；撤销或更换分享码后，服务端直接删除旧分享的记录。
- 分享者可以在 App 中同步当前学校的校历时间；管理员之后修正配置不会悄悄改变已发布的分享。
- 可以把分享课表设为小组件和实时活动的提示来源；它不会替换 App 主界面的课表。
- 内置 NJU 配置仅用于演示和校准，使用前应按实际校历与作息核对。

详细的服务端启动、管理员网页、API、APNs 密钥和安全边界见 [`server/README.md`](../server/README.md)。

### 每张课表的编辑与作息

- 在「设置 → 我的课表 → 对应课表 → 编辑课表」管理课程，编辑页固定操作这张课表。
- 同一张课表内，去除首尾空白后名称相同的安排归为一门课；不同周次、节次、教室、教师及收起状态均保留。导入、追加导入、手动编辑、恢复备份及旧版本升级时统一分组，不同课表互不合并。
- 「节次时间」中的「使用自定义节次时间」开关可切换自定义与学校下发作息，关闭后保留自定义配置。修改后点保存生效。
- 自定义作息支持基础时间表和按每年日期切换的多套时间表，例如 05-01 起夏令作息、10-01 起冬令作息。设置日期作息后按最近生效日期选择，跨年沿用上一年最后一套；没有日期作息时使用基础时间表。
- 学校刷新不会覆盖自定义作息；自定义配置随本地备份和 iCloud 同步保存，分享码携带当前启用的作息快照（需配套更新服务端）。课表、小组件、日历导出及本地课表提醒使用当前选择的作息。
