# 实时活动截图来源

README 中的 `live-lock-screen-system.png`、`live-island-system.png` 和 `live-island-expanded-system.png` 于 2026 年 9 月 30 日截取，使用当前项目的 Debug 构建，运行环境为 iPhone 18 Pro 模拟器、iOS 27.0。

通过 `NAPTABLE_DEBUG_LIVE_ACTIVITY` 启动带有示例课程的 ActivityKit 实时活动。退出 App 后截取系统的紧凑态，长按灵动岛截取展开态，在系统锁屏样式的通知中心截取实时活动卡片。课程、老师和教室均为演示数据。

图片来自系统截图，仅裁剪展示区域；没有重新绘制外形、相机区域、边距、圆角或文字布局。这些是模拟器截图，尚未经真机截图核对。`scripts/widget-gallery/GalleryRenderer.swift` 中自行拼接的灵动岛预览没有用于这组三张图。
